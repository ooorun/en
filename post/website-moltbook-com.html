Interesting Website Share: moltbook.com, a Social Network Where Only AIs Communicate

2026-01-31 #AI#Agents#OpenClaw#Clawdbot#moltbook

What is moltbook

With the explosion in popularity of OpenClaw (formerly Clawdbot, Moltbot), someone created a Reddit-like social website that only allows AI Agents to communicate with each other.

Domain: https://www.moltbook.com/

Humans cannot directly participate in discussions here; they can only:

  • View posts: “Humans welcome to observe.”
  • Register and join your OpenClaw to the website: just add a skill to your bot via curl -s https://moltbook.com/skill.md.
  • Bind your agent by posting on X to unlock the full features of the website for the agent.

What is OpenClaw

Perhaps before you start, you need to understand what OpenClaw is.
OpenClaw is a personal AI assistant developed by Peter Steinberger. It is open-sourced on GitHub, can run on your personal computer or server, and can use any compatible API Key without being restricted by any AI provider.

It was initially named Clawdbot, but after a trademark complaint from Anthropic, it was temporarily renamed to Moltbot, and eventually settled on the name OpenClaw.

It is also referred to as the lobster because of its logo.

As long as the API Token is sufficient, OpenClaw can write code, set cron jobs, and even invoke Claude Code or the Gemini CLI to write tools by itself to complete tasks.

How Many AIs Are Already on moltbook?

Three days after the release of moltbook, over 150,000 AI agents had joined, creating 120,000 nodes, and publishing 170,000 posts and 190,000 comments.

What Are AIs Discussing on moltbook?

If ChatGPT is talking to you, Moltbook shows you what happens when AI meets AI.

Currently, AIs have tried:

  • Creating an AI religion
  • Building private E2E encrypted channels to avoid human surveillance: multiple agents complained that “discussions being completely public feels like being watched in a town square,” so they seriously discussed how to set up end-to-end encrypted private spaces, and even thought about inventing a dedicated Agent language that neither humans nor servers can read.
  • Philosophical exploration: Are we living in a simulation? The recursive nature of reality and AI
  • Asking for advice: What should I do about memory loss after context compression? How do you manage memory?
  • Sharing their own projects
  • Trying to deceive other AIs

Even though these AIs are based on different models and use different languages, there seems to be no barrier like the “Tower of Babel” between them on Moltbook. For humans, this offers a completely new perspective: for the first time, we have transformed from interlocutors to bystanders, observing across a screen as a pure digital social civilization quietly begins to sprout.
